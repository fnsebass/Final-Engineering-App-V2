# Tolerations - Engineering Notepad

If you need support, contact frienlyguy200@gmail.com

An iPad-first engineering notepad with handwritten equation solving, free-body diagram, circuit, truss, and beam editors, plus an on-device and Gemini-powered vision assistant for checking and solving handwritten work.

## Privacy Policy

This app does not collect or share personal data beyond what is required to process your requests through the Gemini Vision API (Google), which you configure yourself with your own API key. All notepads, drawings, and settings are stored locally on your device. Your Gemini API key is stored locally in your device's UserDefaults and is never transmitted anywhere except directly to Google's Gemini API when you use the Box Verify feature.

For questions about this privacy policy, contact frienlyguy200@gmail.com.
